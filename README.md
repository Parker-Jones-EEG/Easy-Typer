# Easy Typer (Dewey AI) ⌨️✨

A lightweight macOS menu bar app that humanizes AI-generated text (or generates fresh paragraphs from a copied prompt) and types it naturally into any document with realistic cadence, typos, and self-corrections.

## Features
- **AI Humanizer & Prompt Generator:** Uses local **Ollama (`llama3.2`)** with 5 selectable writing tones (*Natural Everyday, Casual Student, Concise Pro, Academic Clean, Punchy Direct*), plus a built-in offline rule-based fallback.
- **20–400 WPM Speed Slider:** Smooth human pacing up to high-speed burst typing.
- **Realistic Typos & Self-Corrections:** Adjustable sliders for QWERTY neighbor mistakes and backspaced corrections.
- **Menu Bar Native:** Lives quietly in your top macOS menu bar and saves your preferences automatically.

## Quick Install (macOS)
1. *(Optional, recommended)* Download and open [Ollama](https://ollama.com).
2. Download or clone this repository:
   ```bash
   git clone (https://github.com/Parker-Jones-EEG/Easy-Typer)
   cd Easy-Typer
   ```
3. Double-click **`Install_and_Run.command`** (or run `./Install_and_Run.command` in Terminal).
4. **Grant Accessibility Permission:** When prompted by macOS, open **System Settings → Privacy & Security → Accessibility** and toggle **Easy Typer** ON so it can type into your documents.

## Emergency Stop
Move your mouse cursor quickly into **any corner of your screen** to immediately stop typing.
